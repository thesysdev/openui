## Quickstart

To create a new agent app, run the OpenUI CLI and customize the project it generates. You need Node.js 20 or later:

```bash
npx @openuidev/cli@latest create
```

## How it works

OpenUI works with any agent framework and chat UI. The agent writes its responses in [OpenUI Lang](/docs/openui-lang), and the chat UI renders them with the OpenUI renderer. The agent loop, tools, and conversation stay the way they are.

<AgentTurnDiagram showSteps={false} />

Every agent needs two changes:

1. **The backend** adds instructions generated from the component library to the agent's system prompt, so the model writes OpenUI Lang.
2. **The chat UI** renders the streamed OpenUI Lang with the renderer, and sends user interactions in the generated interface back to the agent.

For a step-by-step walkthrough of one turn, read the [full explanation](/docs/build-agents/how-it-works).

## Run it in production

Route model requests through [Gateway](/docs/gateway) to correct invalid OpenUI Lang as it streams and fail over to another provider when one is unavailable. See [OpenUI in production](/docs/production) for Autofix, Reliability Monitoring, and deployment.
