This example uses the [Vercel AI SDK](https://ai-sdk.dev/) (`streamText`, `tool()`, `toUIMessageStreamResponse()`) as the agent backend and OpenUI's `<AgentInterface />` as the chat UI. The browser decodes the AI SDK UIMessage stream with `vercelAIAdapter()`.

Answers use `@openuidev/intelligent-ui-library` (root `Col`). `@openuidev/react-ui` supplies the chat window, adapters, theming and styles.

## How it connects

The API route calls `streamText` through OpenUI Gateway with OpenUI Lang instructions and tools defined with `tool()`. When the model calls a tool, the AI SDK executes it server-side and continues — up to 5 steps. The response is a UIMessage stream.

The page passes that stream to `<AgentInterface />`:

```tsx
"use client";

import {
  AgentInterface,
  fetchLLM,
  useSystemThemeMode,
  vercelAIAdapter,
  vercelAIMessageFormat,
} from "@openuidev/react-ui";
import { library, ThemeProvider } from "@openuidev/intelligent-ui-library";
import "@openuidev/react-ui/styles/index.css";

const llm = fetchLLM({
  url: "/api/chat",
  streamAdapter: vercelAIAdapter(),
  messageFormat: vercelAIMessageFormat,
});

export default function Page() {
  const mode = useSystemThemeMode();

  return (
    <ThemeProvider mode={mode}>
      <AgentInterface
        llm={llm}
        componentLibrary={library}
        agentName="OpenUI + Vercel AI SDK"
        theme={{ mode }}
      />
    </ThemeProvider>
  );
}
```

Pass the same mode to the library's `ThemeProvider` and the chat's `theme`: the component library cannot read react-ui's theme. This snippet uses in-memory storage; the full example adds browser local storage for threads and messages. Start a new chat for current components if you have saved answers from the old library.

## Component library and prompt

Install `@openuidev/intelligent-ui-library` alongside the chat packages (the standalone example pins `0.0.2`). The CLI reads `src/library.ts`:

```ts
export { library, promptOptions } from "@openuidev/intelligent-ui-library";
```

The full example extends these prompt options with two form rules, preserving the library's examples and `additionalRules`. Generate the spec before running the server:

```bash
openui generate src/library.ts --spec --out src/generated/spec.json
```

`src/lib/cloud-prompt.ts` loads that spec and builds the system prompt in cloud mode:

```ts
import { generateSystemPrompt } from "@openuidev/lang-core";
import spec from "@/generated/spec.json";

const { promptOptions, ...library } = spec;
const systemPrompt = generateSystemPrompt({ cloud: true, library, promptOptions });
```

The example's `cloudInstructions()` performs this step on the server. Its `predev`, `prebuild` and `preverify` scripts regenerate the spec automatically.

## Backend

```ts
import { cloudInstructions } from "@/lib/cloud-prompt";
import { tools } from "@/lib/tools";
import { createOpenAI } from "@ai-sdk/openai";
import { convertToModelMessages, stepCountIs, streamText } from "ai";

const gateway = createOpenAI({
  baseURL: "https://api.thesys.dev/v1/embed",
  apiKey: process.env.THESYS_API_KEY,
});

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: gateway.chat("google/gemini-3.6-flash-free"),
    system: cloudInstructions(),
    messages: await convertToModelMessages(messages),
    tools,
    stopWhen: stepCountIs(5),
  });
  return result.toUIMessageStreamResponse();
}
```

Tools live in `src/lib/tools.ts` (`get_weather`, `get_stock_price`, `search_web`).

## Project layout

```
examples/agent-frameworks/vercel-ai-sdk/
|- src/app/page.tsx           # AgentInterface with the Vercel AI stream adapter
|- src/app/api/chat/route.ts  # streamText() through OpenUI Gateway
|- src/lib/cloud-prompt.ts    # Generated OpenUI Lang instructions
|- src/lib/tools.ts           # Vercel AI SDK tool() definitions
|- src/library.ts             # Component library used to generate the prompt spec
```

## Run the example

Run these commands from `examples/agent-frameworks/vercel-ai-sdk`.

1. Install dependencies:

```bash tab="pnpm" tab-group="pkg"
cd examples/agent-frameworks/vercel-ai-sdk
pnpm install --ignore-workspace
```

```bash tab="bun" tab-group="pkg"
cd examples/agent-frameworks/vercel-ai-sdk
bun install
```

```bash tab="yarn" tab-group="pkg"
cd examples/agent-frameworks/vercel-ai-sdk
yarn install
```

```bash tab="npm" tab-group="pkg"
cd examples/agent-frameworks/vercel-ai-sdk
npm install
```

2. Create a `.env.local` file with your Gateway key:

```bash
THESYS_API_KEY=sk-th-...
```

3. Start the dev server:

```bash tab="pnpm" tab-group="pkg"
pnpm dev
```

```bash tab="bun" tab-group="pkg"
bun dev
```

```bash tab="yarn" tab-group="pkg"
yarn dev
```

```bash tab="npm" tab-group="pkg"
npm run dev
```

## Use a different chat UI

This guide renders the agent with Agent Interface. The backend doesn't depend on it: to use another chat UI, keep the backend from this guide, connect the chat UI to the Vercel AI SDK with that chat UI's own integration, then follow its OpenUI guide to render responses and handle actions.
