Gateway model identifiers use a `{provider}/{model}` convention across the Responses and Chat Completions APIs. Keeping the provider in the identifier makes routing explicit and lets the application switch models without changing clients.

For example, use `openai/gpt-5.6-sol`, not `gpt-5.6-sol`.
