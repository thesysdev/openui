---
title: Search API
description: Run a web search or an image search with one API call, without a model.
---

Send a search query and get the results back as JSON. No model is involved: you get the raw results to use in your own code or to pass to any model.

**Endpoints:**

- `POST https://api.thesys.dev/v1/search/web`
- `POST https://api.thesys.dev/v1/search/images`

Send your Thesys API key as a bearer token. Create one in the [Thesys Console](https://console.thesys.dev/keys) and keep it on your server. See [Authentication](/docs/gateway/authentication).

These endpoints take plain JSON over HTTP. They are not part of the OpenAI-compatible API, so call them with `fetch` or any HTTP client.

## Search the web

```bash
curl https://api.thesys.dev/v1/search/web \
  -H "Authorization: Bearer $THESYS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "query": "nestjs 11 release notes", "num_results": 5 }'
```

```json
{
  "query": "nestjs 11 release notes",
  "results": [
    {
      "title": "NestJS 11 is now available",
      "url": "https://example.com/nestjs-11",
      "text": "NestJS 11 brings ...",
      "published_date": "2026-01-15",
      "favicon": "https://example.com/favicon.ico"
    }
  ],
  "usage": { "search_units": 1 }
}
```

### Request

| Field             | Type     | Required | Purpose                                                                                                  |
| ----------------- | -------- | -------- | -------------------------------------------------------------------------------------------------------- |
| `query`           | string   | Yes      | What to search for. 1 to 2,048 characters.                                                               |
| `num_results`     | integer  | No       | How many results to return, from 1 to 10. The default is 5.                                              |
| `include_domains` | string[] | No       | Only return results from these domains, for example `["nestjs.com"]`.                                    |
| `user_location`   | string   | No       | The searcher's country as a two-letter code, for example `"FR"`. Results are localized for that country. |

### Result

| Field            | Type   | Always present | Content                           |
| ---------------- | ------ | -------------- | --------------------------------- |
| `title`          | string | Yes            | The page title.                   |
| `url`            | string | Yes            | The page URL.                     |
| `text`           | string | No             | Text extracted from the page.     |
| `published_date` | string | No             | When the page was published.      |
| `author`         | string | No             | The page author.                  |
| `image`          | string | No             | The URL of the page's main image. |
| `favicon`        | string | No             | The URL of the site's favicon.    |

## Search images

```bash
curl https://api.thesys.dev/v1/search/images \
  -H "Authorization: Bearer $THESYS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "query": "golden gate bridge at night", "num_results": 3 }'
```

```json
{
  "query": "golden gate bridge at night",
  "results": [
    {
      "title": "Golden Gate Bridge at night",
      "image_url": "https://images.example.com/ggb-night.jpg",
      "page_url": "https://example.com/san-francisco-at-night",
      "source": "example.com",
      "width": 1200,
      "height": 800,
      "thumbnail_url": "https://thumbs.example.com/ggb-night.jpg",
      "mime_type": "image/jpeg"
    }
  ],
  "usage": { "search_units": 1 }
}
```

### Request

| Field         | Type    | Required | Purpose                                                    |
| ------------- | ------- | -------- | ---------------------------------------------------------- |
| `query`       | string  | Yes      | What to search images for. 1 to 2,048 characters.          |
| `num_results` | integer | No       | How many images to return, from 1 to 10. The default is 5. |

### Result

| Field           | Type    | Always present | Content                                   |
| --------------- | ------- | -------------- | ----------------------------------------- |
| `title`         | string  | Yes            | The title of the image or its page.       |
| `image_url`     | string  | Yes            | The URL of the image file.                |
| `page_url`      | string  | Yes            | The URL of the page that shows it.        |
| `source`        | string  | Yes            | The domain of that page.                  |
| `width`         | integer | No             | The image width in pixels.                |
| `height`        | integer | No             | The image height in pixels.               |
| `thumbnail_url` | string  | No             | The URL of a smaller copy.                |
| `mime_type`     | string  | No             | The image type, for example `image/jpeg`. |

Both answers also carry `usage.search_units`, the number of searches you are charged for. It is always 1.

## Call from TypeScript

```ts title="server.ts"
async function searchWeb(query: string) {
  const response = await fetch("https://api.thesys.dev/v1/search/web", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.THESYS_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ query, num_results: 5 }),
  });
  if (!response.ok) {
    const { error } = await response.json();
    throw new Error(`${response.status} ${error.type}: ${error.message}`);
  }
  return response.json();
}
```

## Data

We send your query to a third-party search provider to run the search. We don't store the query or the results, apart from standard request logs.

## Pricing

Each search that returns `200` is charged once from your [Gateway Credits](/docs/gateway/pricing-credits), even if it finds no results:

- **Web search:** the search provider's price, with no markup. Currently $0.007 per search.
- **Image search:** $0.005 per search.

A search that fails costs nothing. Searches don't count toward the API calls included in your plan. If your credits can't cover one search, the call fails with `429` and no search runs.

## Errors

An error answer looks like this. For a `400`, `message` lists every problem found.

```json
{
  "error": {
    "message": ["num_results must not be greater than 10"],
    "type": "invalid_request_error",
    "param": null
  }
}
```

| Status | Type                    | When                                                                                                                                                      |
| ------ | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `400`  | `invalid_request_error` | `query` is missing, empty, or longer than 2,048 characters; `num_results` is not 1 to 10, or `user_location` is not a two-letter country code.            |
| `401`  | `invalid_api_key`       | The API key is missing or invalid.                                                                                                                        |
| `429`  | `rate_limit_error`      | Your organization is out of credits, has reached its spend limit, or has billing suspended. Retrying won't help until you add credits or raise the limit. |
| `500`  | `internal_server_error` | The search provider failed. Nothing is charged. You can retry.                                                                                            |

On some older accounts, the `type` of a `429` is `ERR_QUOTA_EXCEEDED` or `ERR_BILLING_THRESHOLD_EXCEEDED` instead.
