---
title: Search API
description: Run a web search or an image search with one API call, without a model.
---

The Search API runs the same web search and image search that the [hosted tools](/docs/gateway/api/responses/hosted-tools) run inside a Responses request, but on their own. Send a query and get the results back as JSON. No model is called, so you can use the results in your own pipeline, cache them, or pass them to any model.

**Endpoints:**

- `POST https://api.thesys.dev/v1/search/web`
- `POST https://api.thesys.dev/v1/search/images`

Both endpoints authenticate with your inference API key. See [Authentication](/docs/gateway/authentication). Call them from your server, never from the browser.

## Search the web

```bash
curl https://api.thesys.dev/v1/search/web \
  -H "Authorization: Bearer $THESYS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "query": "nestjs 11 release notes", "num_results": 5 }'
```

```json
{
  "query": "nestjs 11 release notes",
  "results": [
    {
      "title": "NestJS 11 is now available",
      "url": "https://example.com/nestjs-11",
      "text": "NestJS 11 brings ...",
      "published_date": "2026-01-15",
      "favicon": "https://example.com/favicon.ico"
    }
  ],
  "usage": { "search_units": 1 }
}
```

### Request

| Field             | Type     | Required | Purpose                                                                            |
| ----------------- | -------- | -------- | ---------------------------------------------------------------------------------- |
| `query`           | string   | Yes      | What to search for. 1 to 2,048 characters.                                         |
| `num_results`     | integer  | No       | How many results to return, from 1 to 10. The default is 5.                        |
| `include_domains` | string[] | No       | Only return results from these domains, for example `["nestjs.com"]`.              |
| `user_location`   | string   | No       | Where the searcher is, to rank local results first, for example `"Paris, France"`. |

### Result

| Field            | Type   | Always present | Content                           |
| ---------------- | ------ | -------------- | --------------------------------- |
| `title`          | string | Yes            | The page title.                   |
| `url`            | string | Yes            | The page URL.                     |
| `text`           | string | No             | Text extracted from the page.     |
| `published_date` | string | No             | When the page was published.      |
| `author`         | string | No             | The page author.                  |
| `image`          | string | No             | The URL of the page's main image. |
| `favicon`        | string | No             | The URL of the site's favicon.    |

## Search images

```bash
curl https://api.thesys.dev/v1/search/images \
  -H "Authorization: Bearer $THESYS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "query": "golden gate bridge at night", "num_results": 3 }'
```

```json
{
  "query": "golden gate bridge at night",
  "results": [
    {
      "title": "Golden Gate Bridge at night",
      "image_url": "https://images.example.com/ggb-night.jpg",
      "page_url": "https://example.com/san-francisco-at-night",
      "source": "example.com",
      "width": 1200,
      "height": 800,
      "thumbnail_url": "https://thumbs.example.com/ggb-night.jpg",
      "mime_type": "image/jpeg"
    }
  ],
  "usage": { "search_units": 1 }
}
```

### Request

| Field         | Type    | Required | Purpose                                                    |
| ------------- | ------- | -------- | ---------------------------------------------------------- |
| `query`       | string  | Yes      | What to search images for. 1 to 2,048 characters.          |
| `num_results` | integer | No       | How many images to return, from 1 to 10. The default is 5. |

### Result

| Field           | Type    | Always present | Content                                   |
| --------------- | ------- | -------------- | ----------------------------------------- |
| `title`         | string  | Yes            | The title of the image or its page.       |
| `image_url`     | string  | Yes            | The URL of the image file.                |
| `page_url`      | string  | Yes            | The URL of the page that shows it.        |
| `source`        | string  | Yes            | The domain of that page.                  |
| `width`         | integer | No             | The image width in pixels.                |
| `height`        | integer | No             | The image height in pixels.               |
| `thumbnail_url` | string  | No             | The URL of a smaller copy.                |
| `mime_type`     | string  | No             | The image type, for example `image/jpeg`. |

## Call from TypeScript

```ts title="server.ts"
async function searchWeb(query: string) {
  const response = await fetch("https://api.thesys.dev/v1/search/web", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.THESYS_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ query, num_results: 5 }),
  });
  if (!response.ok) {
    const { error } = await response.json();
    throw new Error(`${response.status} ${error.type}: ${error.message}`);
  }
  return response.json();
}
```

The endpoints are plain JSON over HTTP. They are not OpenAI compatible, so call them with `fetch` or any HTTP client, not the OpenAI SDK.

## Limits

- One query per call.
- Up to 10 results per call. A search can return fewer than you ask for.
- Image search returns HTTPS images only, with safe search on.
- Web search never returns `wikipedia.org` pages.
- Only non-streaming responses are supported.

## Data

The query is sent to a third-party search provider to run the search. The query and the results are not stored beyond the request logs.

## Pricing

Each successful search is charged from your credits:

- **Web search:** the search provider's cost for the call, without markup.
- **Image search:** a flat price per call.

A search does not use a plan API call, and a failed search is free. Your organization needs enough credit for one call before the search runs. See [Pricing](/docs/gateway/pricing-credits) for the current rates.

## Errors

The endpoints return the same error shape as the Chat Completions and Responses APIs.

| Status | Type                    | When                                                                                         |
| ------ | ----------------------- | -------------------------------------------------------------------------------------------- |
| `400`  | `invalid_request_error` | `query` is missing, empty, or longer than 2,048 characters, or `num_results` is not 1 to 10. |
| `401`  | `authentication_error`  | The API key is missing or invalid.                                                           |
| `429`  | `rate_limit_error`      | The organization has no credits, a spend limit is reached, or billing is suspended.          |
| `500`  | `internal_server_error` | The search provider could not be reached. Nothing is charged.                                |
