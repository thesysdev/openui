## Inside each cookbook

1. **What you'll build**: the scenario and intended experience.
2. **Run the example**: setup instructions and sample data.
3. **Before you start**: prerequisites and the workflow's scope.
4. **Build the workflow**: the recipe's implementation stages.
5. **Verify the experience**: interactions and states to check.
6. **Next steps**: related OpenUI concepts and possible extensions.
