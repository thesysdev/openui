## Inside each cookbook

1. **What you'll build**: the scenario and intended experience.
2. **Run the example**: prerequisites, setup, and sample data.
3. **Numbered build steps**: how the example is built, one stage at a time.
4. **Verify the experience**: interactions and states to check.
5. **Connect your own data**: how to adapt the example and prepare it for deployment.
