OpenUI is a Generative UI toolkit for creating agents that respond with live, interactive interfaces instead of only text. It provides the building blocks for interfaces that adapt to each request while remaining consistent with your product and design system.

<TryItOut />

## OpenUI stack

OpenUI provides the building blocks for creating generated interfaces and running them reliably in production.

<Cards>
  <Card title="OpenUI Lang" href="/docs/openui-lang">
    A compact, line-based language for AI models to generate interfaces from your components. It is
    predictable, stream-friendly, and uses up to [**67% fewer
    tokens**](/docs/openui-lang/benchmarks) than JSON.
  </Card>
  <Card title="Gateway" href="/docs/gateway">
    OpenRouter for Generative UI. Access models across providers with automatic fallbacks and
    correction of invalid OpenUI Lang during streaming.
  </Card>
  <Card title="Autofix" href="/docs/autofix">
    Reliability for your own inference. Correct model output that would break your interface,
    without changing your model provider or inference setup.
  </Card>
  <Card title="Reliability Monitoring" href="/docs/reliability">
    Track generation failures, investigate affected interfaces, and identify recurring errors.
  </Card>
</Cards>

Learn about correction and monitoring options in [OpenUI in production](/docs/production).
