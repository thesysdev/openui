title: Quick Start
description: Run a chat app that builds live dashboards about npm packages and GitHub repositories.
---

The assistant-ui dashboards example is a Next.js chat app whose agent builds dashboards about npm packages and GitHub repositories. Each dashboard loads downloads and releases from npm, stars and commit activity from GitHub, and known vulnerabilities from OSV.dev through an MCP server.

[View source on GitHub →](https://github.com/thesysdev/openui/tree/main/examples/miscellaneous/assistant-ui-dashboards)

## Run the example

```bash
npx @openuidev/cli@latest create --example assistant-ui-dashboards
```

The command creates the app, generates an API key, and starts the dev server.

## Try it

- "Compare weekly npm downloads for react, vue and svelte over the last 6 months."
- "A health dashboard for vercel/next.js: stars, open issues, release cadence and npm downloads."
- "Security overview for lodash: known vulnerabilities by severity and which versions fix them."
- With a dashboard open: "add a GitHub stars row for each framework."

Reload the page to see saved dashboards under **Dashboards**, where each one can be pinned, unpinned, or deleted.
