---
title: Render a dashboard
description: Show a dashboard with LiveArtifactRenderer, from a tool response or an id.
---

`LiveArtifactRenderer` shows a dashboard in the browser. It sends the dashboard's data requests to your interpreter route, and switches to the new version after an edit.

```tsx title="components/dashboard.tsx"
"use client";

import { library } from "@openuidev/dashboard-library";
import { LiveArtifactRenderer } from "@openuidev/react-ui/cloud";

export function Dashboard({ response }: { response: string }) {
  return (
    <LiveArtifactRenderer
      response={response}
      library={library}
      interpreter={{ url: "/api/interpreter" }}
    />
  );
}
```

The renderer must sit inside [`OpenUICloudProvider`](/docs/dashboards/authentication#connect-the-browser), which supplies the user's frontend token.

## Props

| Prop                                    | Description                                                                                                                               |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `response`                              | The response from `create` or `edit`, unchanged.                                                                                          |
| `id`                                    | The dashboard's id, instead of `response`. Use it to open a saved dashboard, such as one from the list.                                   |
| `library`                               | The component library. Use the same library the spec on the server came from.                                                             |
| `interpreter`                           | Where queries run: `{ url, headers? }` for a route, or an async function that takes the request.                                          |
| `preview`                               | `true` (default): a card that opens the dashboard. `false`: the dashboard renders in place.                                               |
| `renderInHtmlElement`                   | The element the dashboard opens in, such as a side panel. Default: under the card.                                                        |
| `isOpen`, `onOpenChange`, `defaultOpen` | Control whether the dashboard is open from its card.                                                                                      |
| `actions`                               | Buttons in the open dashboard's bar, next to the close button.                                                                            |
| `enableProvenance`                      | Show where the data comes from: a Sources button in the bar, inspect mode and a popover per component. See [Data sources](#data-sources). |
| `onError`                               | Receives rendering, query, and loading errors.                                                                                            |
| `pollInterval`                          | How often the open dashboard checks for edits and access changes, in ms (at least 3s). `false`: never.                                    |
| `className`                             | Added to the root element.                                                                                                                |

## Layouts

### Card in the chat

By default, the renderer shows a card with the dashboard's title and status. Clicking it opens the dashboard under the card.

```tsx
<LiveArtifactRenderer response={response} library={library} interpreter={interpreter} />
```

### Side panel

Pass the panel's element as `renderInHtmlElement`. The card stays in the chat, and the dashboard opens in the panel:

```tsx
const [panel, setPanel] = useState<HTMLElement | null>(null);

<>
  <Chat>
    <LiveArtifactRenderer
      response={response}
      library={library}
      interpreter={interpreter}
      renderInHtmlElement={panel}
    />
  </Chat>
  <aside ref={setPanel} />
</>;
```

### In place

With `preview={false}`, the dashboard renders where the renderer is, without a card. Use it for a full page or a panel the app manages itself:

```tsx
<LiveArtifactRenderer id={id} library={library} interpreter={interpreter} preview={false} />
```

In this mode the renderer draws no frame unless a `Chrome` slot is passed. See [Slots](#slots).

### Before the tool returns

The model writes the tool call's arguments before `create` runs, which can take a while. Mount the renderer as soon as the call starts, without `response` or `id`. Until the result arrives it shows the `Pending` slot, a sketch of a dashboard, and then the same renderer streams the dashboard:

```tsx
<LiveArtifactRenderer
  response={toolCall.result} // undefined while the call runs
  library={library}
  interpreter={interpreter}
  preview={false}
/>
```

Unmount it if the call stops or fails without a result, or it stays pending. In `AgentInterface`, `defineLiveArtifactRenderer` from `@openuidev/react-ui/cloud/agent-interface` does both.

The result can arrive before the dashboard is written, while the model still calls your data tools. `Pending` then keeps showing until the dashboard starts streaming. In the middle of the area, the build's feed says what it's doing now: "Thinking…", then the calls by name ("Calling list_orders…" while it calls tools, "Writing and testing revenueByDay…" while it writes scripts), then "Building dashboard…" while it's written.

## Slots

Each part of the renderer is a slot, passed as a child. A slot can be left out to keep the default, given props to change the default's values, or given children to replace its look.

| Slot                                                                          | Region  | What it is                                                                                                 |
| ----------------------------------------------------------------------------- | ------- | ---------------------------------------------------------------------------------------------------------- |
| `Preview`                                                                     | Preview | The card that opens the dashboard.                                                                         |
| `PreviewTitle`, `PreviewDescription`, `PreviewLoader`, `PreviewError`         | Preview | The card's parts.                                                                                          |
| `Chrome`                                                                      | Chrome  | The frame around the open dashboard: a bar, then the content.                                              |
| `ChromeTitle`, `ChromeLoader`, `EditedNotice`, `ChromeActions`, `CloseButton` | Chrome  | The bar's parts.                                                                                           |
| `ProvenanceToggle`                                                            | Chrome  | The Sources button. Only with `enableProvenance`.                                                          |
| `Content`                                                                     | Chrome  | The dashboard itself.                                                                                      |
| `Pending`, `Loading`, `Error`                                                 | Content | Shown only before the dashboard has content, while it loads, or after it fails, even with custom children. |
| `Provenance`                                                                  | Content | What the Sources popover and All sources show. Only with `enableProvenance`.                               |

For example, a full-height panel with its own header:

```tsx
<LiveArtifactRenderer id={id} library={library} interpreter={interpreter} preview={false}>
  <LiveArtifactRenderer.Chrome>
    <header className="panel-header">
      <LiveArtifactRenderer.ChromeTitle />
      <StatusBadge />
    </header>
    <LiveArtifactRenderer.Content className="panel-body">
      <LiveArtifactRenderer.Pending color="#2c59f5" />
      <LiveArtifactRenderer.Loading label="Loading live data…" />
      <LiveArtifactRenderer.Error>
        <DashboardError />
      </LiveArtifactRenderer.Error>
    </LiveArtifactRenderer.Content>
  </LiveArtifactRenderer.Chrome>
</LiveArtifactRenderer>
```

Slots render only in their region: `ChromeTitle` outside `Chrome` renders nothing.

## Renderer state

`useArtifactRenderer()` returns the renderer's state inside any slot:

```tsx
import { useArtifactRenderer } from "@openuidev/react-ui/cloud";

function StatusBadge() {
  const { isStreaming, isFetching, error } = useArtifactRenderer();
  if (error) return <span>Couldn't load</span>;
  if (isStreaming) return <span>Generating</span>;
  if (isFetching) return <span>Loading data</span>;
  return <span>Live</span>;
}

function DashboardError() {
  const { error, retry } = useArtifactRenderer();
  return (
    <div role="alert">
      <p>
        {error?.source === "query" ? "Some data didn't load." : "This dashboard couldn't be shown."}
      </p>
      {retry && <button onClick={retry}>Try again</button>}
    </div>
  );
}
```

| Field                     | Description                                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `id`, `title`             | The dashboard's id and title.                                                                               |
| `isOwner`, `isEditable`   | Whether the user owns it, and whether they can edit, rename, and share it. Kept current while it's open.    |
| `isPending`               | Nothing to show yet: the tool call that makes it is running, or the build hasn't started writing it.        |
| `isStreaming`             | The dashboard is being generated.                                                                           |
| `isEditing`               | A new version is streaming in over the one on screen (an edit).                                             |
| `isFetching`              | Its queries are running.                                                                                    |
| `isLoading`               | Any of the three.                                                                                           |
| `step`                    | During a build, `{ tools, scripts }`: the data tools it's calling and scripts it's writing, empty at first. |
| `justUpdated`             | A newer version replaced the one on screen in the last few seconds.                                         |
| `error`                   | A loading error (`source: "artifact"`) or a query error (`source: "query"`).                                |
| `retry`                   | Retries what failed. Undefined when there's nothing to retry.                                               |
| `isOpen`, `open`, `close` | The open state, when the dashboard has a card.                                                              |
| `preview`                 | Whether the renderer has a card.                                                                            |

## Data sources

With `enableProvenance`, the bar gets a Sources button. It turns on inspect mode, which outlines every component that reads a query; clicking one opens a popover with its queries, formula and results. The chevron beside it opens All sources, which lists every query in the dashboard.

```tsx
<LiveArtifactRenderer id={id} library={library} interpreter={interpreter} enableProvenance />
```

Pass `describeSource` to `Provenance` to name your tools and show the code they ran:

```tsx
import type { SourceDescription } from "@openuidev/react-ui/cloud";

function describeSource(toolName: string, args: unknown): SourceDescription | undefined {
  if (toolName === "postgres_query") {
    return { kind: "Postgres", codeLabel: "SQL", code: (args as { sql: string }).sql };
  }
}

<LiveArtifactRenderer id={id} library={library} interpreter={interpreter} enableProvenance>
  <LiveArtifactRenderer.Chrome>
    <LiveArtifactRenderer.ChromeActions />
    <LiveArtifactRenderer.Content>
      <LiveArtifactRenderer.Provenance describeSource={describeSource} />
    </LiveArtifactRenderer.Content>
  </LiveArtifactRenderer.Chrome>
</LiveArtifactRenderer>;
```

### Your own button and contents

Children of `ProvenanceToggle` replace the Sources button, and children of `Provenance` replace what the popover and All sources show. Both read `useArtifactProvenance()`:

```tsx
import { useArtifactProvenance } from "@openuidev/react-ui/cloud";

function SourcesContents() {
  const { selection, sources } = useArtifactProvenance();
  const component = selection && sources?.components[selection.id];
  if (!sources || !component) return null;

  const shown = selection.prop ? component.props[selection.prop] : component;
  const queries = shown?.queries.map((name) => sources.queries[name]); // tool, args, data
  const formula = shown?.via.map((name) => `${name} = ${sources.formulas[name]}`);
  return <div>{/* your UI */}</div>;
}

<LiveArtifactRenderer.Provenance>
  <SourcesContents />
</LiveArtifactRenderer.Provenance>;
```

| Field                           | Description                                                                                                                                                                        |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isInspecting`, `setInspecting` | Inspect mode.                                                                                                                                                                      |
| `selection`                     | The clicked component's `id` (its statement's name, or `lead.1` for a component written inside `lead`), `prop`, `element` and `propElement`.                                       |
| `clearSelection`                | Clears the selection and closes its popover.                                                                                                                                       |
| `isPopoverOpen`                 | Whether a component's popover is open.                                                                                                                                             |
| `isAllSourcesOpen`              | Whether All sources is open.                                                                                                                                                       |
| `openAllSources`                | Opens All sources under the element that called it.                                                                                                                                |
| `sources`                       | [`useDataSources()`](/docs/api-reference/react-lang#context-hooks-inside-renderer-components): every component's sources and every query. Null while nothing is open or inspected. |

### Finding components

In React on the web, components are found through React's own tree, with no change to the library. Where that tree can't be read, only components marked with `bindSource()` are found. To outline the element that shows a prop's value instead of the whole component, mark it with `bindSource("prop")` (see [`defineComponent`](/docs/api-reference/react-lang#definecomponentconfig)). A component inside a statement, such as one Kpi among several, gets its position as its id (`lead.1`), so an edit can renumber it and clear the selection.

Pass the same `library` object on every render, such as one created at module level: a new library each render makes the whole dashboard render again.

### Styling

The outlines read `--openui-inspect-color`, `--openui-inspect-outline`, `--openui-inspect-active-outline` and `--openui-inspect-outline-offset`. Set them on `.openui-artifact-content` or any element around it:

```css
.openui-artifact-content {
  --openui-inspect-color: #7c3aed;
}
```

Inspect state is on data attributes: `data-openui-inspecting` on the renderer's root, and `data-openui-bound`, `data-openui-hover` and `data-openui-selected` on the outlined elements. The popover and All sources are portaled to `body`, as `.openui-sources-popover` and `.openui-sources-menu`.

## Theme

`ThemeProvider` from `@openuidev/dashboard-library` sets the components' mode, `"light"` (default) or `"dark"`, and takes `lightTheme` and `darkTheme` overrides. It's optional.

## Interpreter as a function

`interpreter` also takes an async function, such as a server action. It receives the request and returns the result:

```tsx
<LiveArtifactRenderer
  response={response}
  library={library}
  interpreter={(request) => runQuery(request)}
/>
```

The request has `id`, `version`, `name`, and `arguments`. Pass it to `dashboards.interpreter.execute()` on the server, as in the [interpreter route](/docs/dashboards/connect-data#add-the-interpreter-route).
