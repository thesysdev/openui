## Where to start

- **A React chat app, fast:** [`@openuidev/react-ui`](/docs/api-reference/react-ui) gives you `AgentInterface`, a ready-made chat surface.
- **Your own React chat UI:** [`@openuidev/react-headless`](/docs/api-reference/react-headless) for chat state and streaming, with [`@openuidev/react-lang`](/docs/api-reference/react-lang) to render OpenUI Lang.
- **A backend, or a framework other than React:** [`@openuidev/lang-core`](https://github.com/thesysdev/openui/tree/main/packages/lang-core) for prompts and parsing, or the [Vue](/docs/api-reference/vue-lang), [Svelte](/docs/api-reference/svelte-lang), or [Angular](/docs/api-reference/angular-lang) bindings.
