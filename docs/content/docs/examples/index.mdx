## Runnable examples

Every example in the [`examples/`](https://github.com/thesysdev/openui/tree/main/examples) folder is a standalone app. Scaffold one with the OpenUI CLI:

```bash
npx @openuidev/cli@latest create --example <name>
```

The CLI copies the example into a new folder and asks for the API key it needs, which it saves to `.env`. Most examples use a `THESYS_API_KEY` from the [Thesys console](https://console.thesys.dev/keys).
