## Curio

An open-source reading companion that uses OpenUI generative UI to explore words and phrases without leaving the text.

[GitHub](https://github.com/JoseEstevez520/curio) · [Website](https://curio-landing-phi.vercel.app)

## OpenUI Forge

A coding-assistant toolkit for generating and wiring OpenUI integrations across common AI stacks.

[GitHub](https://github.com/OthmanAdi/openui-forge) · [Website](https://spruce-prism-8yya.here.now/)

## GAIA

A proactive personal AI assistant for inboxes, calendars, tools, and workflows built with OpenUI.

[GitHub](https://github.com/theexperiencecompany/gaia) · [Website](https://heygaia.io/)

## Noetic

An agent framework integration for returning OpenUI interfaces through a streaming output codec, durable surface layer, and transport.

[Docs](https://noetic.tools/docs/framework/generative-ui)

## Field Theory UI

A local-first web interface for exploring X/Twitter bookmarks with OpenUI-powered interactive dashboards.

[GitHub](https://github.com/Gitmaxd/field-theory-ui)

## Open WebUI plugin

Bring OpenUI-rendered interactive responses into Open WebUI chat workflows.

[GitHub](https://github.com/thesysdev/openwebui-plugin) · [Guide](https://openwebui.com/posts/generative_ui_plugin_for_open_webui_6c017d62) · [Open WebUI](https://github.com/open-webui/open-webui)

## Ollama integration

Use OpenUI with local Ollama models through an OpenAI-compatible route or an Open WebUI workflow.

[Article](https://dev.to/shogun444/i-tested-openui-with-ollama-models-heres-what-actually-worked-45m7) · [GitHub](https://github.com/shogun444/openui-ollama-localsetup) · [Ollama](https://ollama.com)

## Genui VS Code extension

Preview `.openui` files live in VS Code and Open VSX-compatible editors while agents write OpenUI Lang.

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Ginaphi.generative-ui) · [Open VSX](https://open-vsx.org/extension/ginaphi/generative-ui)

## OpenUI Plotly

Scaffold a Next.js generative UI chat with typed Plotly chart components for data-heavy responses.

[npm](https://www.npmjs.com/package/@vishxrad/openui-plotly?activeTab=readme)

## AI Native Dashboard

An OpenUI-powered infinite canvas for generating movable, resizable dashboard widgets from natural language.

[GitHub](https://github.com/jaibhasin/AI-Native-Dashboard)

## Add your project

[Open an issue](https://github.com/thesysdev/openui/issues) or a pull request with:

- A link to the project and a one-line description
- Install steps
- A maintainer contact and the license
- Whether it is official, community, or experimental

You can also share it in [Discord](https://discord.com/invite/Pbv5PsqUSv).
