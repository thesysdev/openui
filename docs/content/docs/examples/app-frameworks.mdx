---
title: App frameworks
description: Application frameworks and platforms that host an OpenUI client or server.
---

Each example scaffolds with the OpenUI CLI and asks for your `THESYS_API_KEY` from the [Thesys console](https://console.thesys.dev/keys).

## Angular

An NG-ZORRO X chat interface rendering OpenUI Cloud responses with the Angular runtime.

```bash
npx @openuidev/cli@latest create --example angular
```

[Source](https://github.com/thesysdev/openui/tree/main/examples/app-frameworks/angular) · [Guide](/docs/api-reference/angular-lang)

## FastAPI

A Python FastAPI streaming backend with a React OpenUI client.

```bash
npx @openuidev/cli@latest create --example fastapi
```

[Source](https://github.com/thesysdev/openui/tree/main/examples/app-frameworks/fastapi)

## React Native

An Expo client rendering native OpenUI components from a Next.js backend stream.

```bash
npx @openuidev/cli@latest create --example react-native
```

[Source](https://github.com/thesysdev/openui/tree/main/examples/app-frameworks/react-native)

## Svelte

```bash

```

[Source](https://github.com/thesysdev/openui/tree/main/examples/app-frameworks/svelte)
