Unless noted, each example scaffolds with the OpenUI CLI and asks for your `THESYS_API_KEY` from the [Thesys console](https://console.thesys.dev/keys).

## Autofix

Direct OpenAI generation repaired with `@openuidev/server` Autofix.

```bash
npx @openuidev/cli@latest create --example autofix
```

This example needs both an `OPENAI_API_KEY` and a `THESYS_API_KEY`. Set them as its README describes.

[Source](https://github.com/thesysdev/openui/tree/main/examples/miscellaneous/autofix) · [Guide](/docs/autofix)
