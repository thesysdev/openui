---
title: Agent frameworks
description: Agent runtimes and orchestration frameworks that produce or stream OpenUI output.
---

Each example scaffolds with the OpenUI CLI and asks for your `THESYS_API_KEY` from the [Thesys console](https://console.thesys.dev/keys).

## Google ADK

A Google ADK TypeScript agent streaming OpenUI Lang to a Next.js client.

```bash
npx @openuidev/cli@latest create --example google-adk
```

[Source](https://github.com/thesysdev/openui/tree/main/examples/agent-frameworks/google-adk)

## LangGraph Platform

A DeepAgents graph on LangGraph Platform, streamed to OpenUI through the LangChain adapter.
