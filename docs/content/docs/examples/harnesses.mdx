## Grok Build

Grok Build coding sessions and tool activity in Agent Interface.

```bash
npx @openuidev/cli@latest create --example grok-build
```

The CLI asks for your `XAI_API_KEY`.

[Source](https://github.com/thesysdev/openui/tree/main/examples/harnesses/grok-build)

## Pi

A Pi coding-agent session streamed into Agent Interface.

```bash
npx @openuidev/cli@latest create --example pi
```

The CLI asks for your `THESYS_API_KEY` from the [Thesys console](https://console.thesys.dev/keys).

[Source](https://github.com/thesysdev/openui/tree/main/examples/harnesses/pi) · [Guide](/docs/agent/agent-runtimes/pi)
