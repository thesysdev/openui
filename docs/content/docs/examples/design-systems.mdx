Each example scaffolds with the OpenUI CLI and asks for your `THESYS_API_KEY` from the [Thesys console](https://console.thesys.dev/keys).

## Material UI

A broad Material UI component library for generated interfaces.

```bash
npx @openuidev/cli@latest create --example material-ui
```

[Source](https://github.com/thesysdev/openui/tree/main/examples/design-systems/material-ui)
