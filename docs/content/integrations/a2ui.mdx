<Steps>

<Step title="Create a client" source="https://www.openui.com/docs/api-reference/a2ui">

Create one client per renderer. Give it the JSON schema of the same OpenUI component library the renderer uses, and an `onMessage` callback that sends renderer-to-agent messages over your transport: SSE, WebSocket, AG-UI or an agent SDK.

```ts title="lib/a2ui.ts"
import { createA2UIClient } from "@openuidev/a2ui";
import { openuiLibrary } from "@openuidev/react-ui";

export const client = createA2UIClient({
  schema: openuiLibrary.toJSONSchema(),
  rootName: openuiLibrary.root,
  rendererCapabilities: {
    "v1.0": { supportedCatalogIds: ["com.example:openui"] },
  },
  onMessage(message, metadata) {
    transport.send({ message, metadata }); // Your transport back to the agent.
  },
});
```

</Step>

<Step title="Process agent messages" source="https://www.openui.com/docs/api-reference/a2ui">

Pass each decoded agent message to `client.process()` in arrival order. The envelopes are standard A2UI v1.0, but `components` holds OpenUI Lang statements instead of A2UI component JSON. Updates merge by statement ID, so the agent can stream a surface and patch one part of it later.

```ts title="lib/a2ui.ts"
await client.process({
  version: "v1.0",
  createSurface: {
    surfaceId: "main",
    catalogId: "com.example:openui",
    dataModel: { user: { name: "Alice" } },
  },
});

await client.process({
  version: "v1.0",
  updateComponents: {
    surfaceId: "main",
    components: [
      "root = Stack([greeting, save])",
      'greeting = TextContent("Hello, " + $user.name)',
      'save = Button("Save", onClick: @ToAssistant("Save these settings"))',
    ],
  },
});
```

</Step>

<Step title="Render the surface in React" source="https://www.openui.com/docs/api-reference/a2ui">

`A2UIRenderer` subscribes to one surface and renders it with your component library. Clicks and form submits go back to the agent as A2UI `action` messages, and OpenUI Lang `Query()` and `Mutation()` calls go back as `callAgentFunction`.

```tsx title="app/surface.tsx"
"use client";

import { A2UIRenderer } from "@openuidev/a2ui/react";
import { openuiLibrary } from "@openuidev/react-ui";
import { client } from "@/lib/a2ui";

export function Surface({ isStreaming }: { isStreaming: boolean }) {
  return (
    <A2UIRenderer
      client={client}
      surfaceId="main"
      library={openuiLibrary}
      isStreaming={isStreaming}
    />
  );
}
```

</Step>
