# Excalifont

The unmodified Latin subset of Excalidraw's Excalifont, used for hand-drawn docs diagrams.

- [Upstream font](https://github.com/excalidraw/excalidraw/blob/4850bf336fe0a8501af49d84deebc7fb56357cc2/packages/excalidraw/fonts/Excalifont/Excalifont-Regular-a88b72a24fb54c9f94e3b5fdaa7481c9.woff2)
- [Upstream metadata and license](https://github.com/excalidraw/excalidraw/blob/4850bf336fe0a8501af49d84deebc7fb56357cc2/packages/excalidraw/fonts/Excalifont/index.ts)
- [Bundled license](./LICENSE.txt): SIL Open Font License 1.1.

Loaded locally through `next/font/local`; diagram rendering waits for the font before measuring labels.
