# `@openuidev/server`

Use `createClient` to fix invalid OpenUI Lang and save completed Chat Completions turns to conversation history on the OpenUI Gateway.

## Install

```bash tab="pnpm" tab-group="pkg"
pnpm add @openuidev/server
```

```bash tab="bun" tab-group="pkg"
bun add @openuidev/server
```

```bash tab="yarn" tab-group="pkg"
yarn add @openuidev/server
```

```bash tab="npm" tab-group="pkg"
npm install @openuidev/server
```

## Create a client

```ts
import { createClient } from "@openuidev/server";

const openUIClient = createClient(); // Reads process.env.THESYS_API_KEY.
```

Explicit options override the environment:

```ts
const openUIClient = createClient({
  apiKey: "your-server-key",
  baseUrl: "https://api.thesys.dev", // Gateway origin, without /v1.
  fetch: customFetch,
});
```

Missing or empty API keys throw `ServerClientError` with `code: "missing_api_key"`. Gateway request errors expose a `code` and HTTP `status`.

## Fix completed output

Fix a completed generation from any model provider:

```ts
import library from "./openui.spec.json";

const result = await openUIClient.autofix.fix({
  library,
  generation: generatedOpenUI,
  messages, // Optional conversation context in Chat Completions format.
  signal,
});
```

`generation` is the completed OpenUI text string. Pass the library spec generated by `openui generate --spec`, including its `schema`. Autofix creates and caches its parser on the first use of each library object. It validates locally and calls the Autofix endpoint only for invalid output.

Results have `status: "already_valid" | "fixed" | "fix_failed"`, `original`, `content`, `fixedErrors`, and `unfixedErrors`. `content` is null if the generation could not be fixed; otherwise render or persist that complete value.

## Fix streaming output

```ts
const result = openUIClient.openai.completions.autofix.stream({
  library,
  stream: completionEvents,
  messages,
  signal,
});
return result.toResponse();
```

For Vercel AI SDK UI message events:

```ts
return openUIClient.vercel.ai.autofix
  .stream({ library, stream: uiMessageEvents, messages, signal })
  .toResponse();
```

The stream exposes `chunks` (native events), `toResponse()` (HTTP output), and `result` (Autofix result or null if validation did not run). Consume either `chunks` or `toResponse()` once. `result` settles after consumption finishes. A failed streamed fix throws `AutofixError` with `code: "fix_failed"` and diagnostics.

## Append Completions messages

```ts
await openUIClient.openai.completions.conversations.appendMessages({
  conversationId: threadId,
  messages: [
    { role: "user", content: lastUserText },
    { role: "assistant", content: assistantText },
  ],
  signal,
});
```

Accepts Chat Completions messages only and returns a `ConversationItemList`. It converts user/assistant messages and function calls/results into Conversations API items; system/developer instructions are skipped. An empty converted turn makes no request. The conversation must already exist. Append only the new turn to avoid duplicate items; writes are not retried automatically.
