Add `OpenUIClient` for live dashboards. `openui.defineDashboard({ library, model, tools?, mcp?, promptOptions? })` takes your app's config once (`library` is a library spec, such as `library.toSpec()` or the JSON from `openui generate --spec`) and returns `create({ title, prompt }, context)` and `edit({ id, prompt }, context)`, which resolve with the tool response as soon as the artifact has an id, plus `interpreter`, whose `execute(request, context, { signal?, timeoutMs? })` runs that dashboard's data tools, and its generated scripts only for the user who owns the artifact. `context` is yours and must include the signed-in `userId`, who owns, edits and runs the dashboard; tools receive it as `(args, context, { signal })`. `mcp` takes an MCP client or `{ client, include?, outputs?, connect? }`, or an array of them for several servers: their tools are listed on first use, offered read-only unless you pick them with `include`, each call goes through `connect(context)` for per-user credentials, and unset optional arguments (`""` or `null`, like a filter nobody picked) are left out. `new OpenUIClient({ appId })` puts users' frontend tokens and artifacts in your app, and generated scripts run only from it. `openui.createFrontendToken({ userId })` mints the signed-in user's frontend token for your token endpoint. The config block is built with `generateSystemPrompt({ cloud: true })`.
