Add `OpenUIClient` for live dashboards. `openui.defineDashboard({ library, model, tools?, mcp?, promptOptions? })` takes your app's config once (`library` is a library spec, such as `library.toSpec()` or the JSON from `openui generate --spec`) and returns `create({ userId, title, prompt })` and `edit({ userId, id, prompt })`, which resolve with `{ id, response }` as soon as the artifact has an id, plus `interpreter`, whose `execute(request, context, { signal?, timeoutMs? })` runs that dashboard's data tools, and its generated scripts only for the user who owns the artifact. `context` is yours and must include the signed-in `userId`; tools receive it as `(context, args, { signal })`. `mcp` takes an MCP client or `{ client, include?, outputs?, connect? }`, or an array of them for several servers: their tools are listed on first use, offered read-only unless you pick them with `include`, and each call goes through `connect(context)` for per-user credentials. `openui.createFrontendToken({ userId })` mints the signed-in user's frontend token for your token endpoint. The config block is built with `generateSystemPrompt({ cloud: true })`.
