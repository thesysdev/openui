Add `openui-server` on PyPI, this package for Python servers. It has the same calls (artifacts, conversations with Chat Completions and LangGraph messages, frontend tokens, live dashboards with their agent tools and MCP server, and Autofix for Chat Completions) in a sync `OpenUIClient` and an async `AsyncOpenUIClient`. It's released with this package, always at the same version.
