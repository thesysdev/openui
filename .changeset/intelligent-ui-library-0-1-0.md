First release of the Intelligent UI component library: 52 components in 6 groups that a model composes into interactive answers, with `Col` as the root. Layout (Col, Row, Box, Grid, Card, Carousel, Popover), text (Title, Text, Markdown, Code, Math and more), inputs (Button, Input, Select, Slider, DatePicker, Timer, Form and more), media and data (Image, Icon, Table, Chart, YouTube), play (Flashcard, Celebration) and drawing (Svg shapes and a sandboxed HtmlView). 59 `@functions` let an answer compute with its own `$variables` without a round trip to the model. `promptOptions` carries generation rules and examples, and `ThemeProvider` sets light or dark mode with theme overrides.
