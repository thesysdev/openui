Stream OpenUI Cloud artifacts into any renderer. `ArtifactStorage` gains an optional `stream(id)` method, which `useOpenuiCloudStorage`'s artifact storage implements over SSE, resuming with `Last-Event-ID`. The new `useArtifactStream({ id, version })` hook shares one stream per artifact across every component showing it, keeps the current version on screen while an edit streams in, and falls back to `get(id)` for storages without `stream`. Also new: `parseArtifactReference()` to read an artifact tool's response, `createInterpreterToolProvider()` to run an artifact's `Query()` calls through your interpreter, `<OpenUICloudProvider token>` to connect renderers to OpenUI Cloud outside `ChatProvider` (or `ArtifactStorageProvider` for any other storage), and the frontend-token helpers (`createFrontendTokenManager`, `createFctFetch`, `toFrontendTokenManager`). `ArtifactStorage` also gains optional `pin`, `unpin` and `delete` (implemented by cloud storage), list results carry `description`, `summary`, `pinned` and `createdAt`, and `list` takes a `pinned` filter. Each artifact stream publishes one `react-headless:artifact` observability event when it's shown or fails. Existing exports are unchanged.
