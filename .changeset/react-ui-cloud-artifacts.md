New `@openuidev/react-ui/cloud` entry for artifacts from OpenUI Cloud: `LiveArtifactRenderer` and `StaticArtifactRenderer` stream an artifact in from an artifact tool's response (or an `id`), run its live data through your interpreter, and show it as a preview card that opens under itself or in your own element, or inline with `preview={false}`. Every part is a slot (`Preview`, `Chrome`, `Content`, `Loading`, `Error`, …) with AgentInterface's omit / props / children modes (the loader and `Error` slots show only while loading or failed, children included), `actions` adds buttons to the open artifact's bar, and `useArtifactRenderer()` exposes the renderer's state. `useArtifactList({ filter })` lists the user's artifacts page by page, and `useArtifactPin()`, `useArtifactUnpin()`, `useArtifactDelete()` and `useArtifactUpdate()` (rename, or save edited content) change them; lists and renderers share one cache, so a change shows everywhere at once and reverts if it fails. The renderer injects its own styles with goober, so it no longer needs `components.css`. `onError` gets `Renderer`'s errors plus an `ArtifactError` (`source: "artifact"`) when the artifact can't be shown. The `@openuidev/react-headless` peer window moves to `>=0.18.2`.
