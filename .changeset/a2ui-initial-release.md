Initial release of `@openuidev/a2ui`, an A2UI v1.0 protocol client that carries OpenUI Lang statements as component payloads. The framework-agnostic core handles surface lifecycle, statement patches, data-model updates, actions, function calls, and renderer capabilities and metadata. The optional `@openuidev/a2ui/react` entrypoint renders surfaces with `@openuidev/react-lang`.
